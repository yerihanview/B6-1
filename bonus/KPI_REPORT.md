> **기준 데이터**: seed.sql 기준 (카테고리 10종, 도서 13권, 회원 12명, 대여 15건)
> **분석 목적**: 도서관 운영 효율성과 회원 서비스 품질을 정량적으로 측정하여 의사결정에 활용한다.
> **산출 방법**: 아래 각 KPI별 SQL을 SQLite에서 직접 실행하여 수치를 도출한다.

## KPI-1. 월별 대여 회전율 (Monthly Turnover Rate)

### 정의

> **대여 회전율 = 해당 월 대여 건수 ÷ 전체 보유 도서 권수**
>
> 보유 도서 대비 얼마나 많은 대여가 발생했는지를 나타내는 활용도 지표이다.
> 값이 1.0이면 보유 도서 전체가 한 번씩 대여된 수준을 의미한다.

### 산출 SQL

```sql
-- KPI-1: 월별 대여 회전율 (대여 건수 / 전체 보유 도서 권수)
SELECT
    strftime('%Y-%m', rental_date)          AS 대여월,
    COUNT(*)                                AS 월별_대여건수,
    (SELECT COUNT(*) FROM books)            AS 전체_도서권수,
    ROUND(
        CAST(COUNT(*) AS REAL)
        / (SELECT COUNT(*) FROM books),
        4
    )                                       AS 대여_회전율
FROM rentals
GROUP BY strftime('%Y-%m', rental_date)
ORDER BY 대여월;
```

### 실측 결과 (seed 데이터, 도서 13권)

| 대여월 | 대여 건수 | 회전율 |
|---|---|---|
| 2026-01 | 1 | 0.0769 |
| 2026-02 | 2 | 0.1538 |
| 2026-03 | 2 | 0.1538 |
| 2026-04 | 1 | 0.0769 |
| 2026-05 | 1 | 0.0769 |
| 2026-06 | 2 | 0.1538 |
| 2026-07 | 2 | 0.1538 |
| 2026-10 | 2 | 0.1538 |
| 2026-11 | 2 | 0.1538 |

### 해석

- 대여가 발생한 9개월의 회전율은 **0.077~0.154** 범위다. 보유 도서 13권 중 매달 1~2권만 대여된 셈이다.
- 8월·9월은 대여 0건으로 회전율이 **0.000**이다(비수기 공백).
- 상반기(1~7월)와 10~11월에 고르게 분포하고, 여름~초가을에 끊긴다. 특정 월에 집중됐다기보다 **월 1~2건의 저회전 상태가 지속**되는 구조다.
- 회전율 1.0은 "모든 도서가 한 달에 한 번씩 대여"를 뜻하므로, 현재는 그 **7.7~15.4%** 수준이다.

### 개선 액션

| 우선순위 | 액션 | 기대 효과 |
|---|---|---|
| 1 | 비수기(1~3월) 신간 도서 집중 입고 및 추천 이벤트 운영 | 비수기 회전율 0.1 이상으로 개선 |
| 2 | 회전율 0.05 미만 지속 도서(6개월 이상 미대여)를 폐기 또는 기증 처리 | 실질 보유 도서 품질 향상 |
| 3 | 인기 카테고리(소설·컴퓨터) 복본 확보 | 대기 수요 해소 및 회전율 상승 |

## KPI-2. 최다 대여 도서 TOP 3 (Most Rented Books)

### 정의

> **최다 대여 도서 = 전체 대여 이력에서 동일 book_id가 가장 많이 등장한 도서**
>
> 회원 선호도와 컬렉션 수요를 파악하여 복본 구매 및 추천 서비스에 활용한다.

### 산출 SQL

```sql
-- KPI-2: 최다 대여 도서 TOP 3
SELECT
    b.book_id,
    b.title                         AS 도서명,
    b.author                        AS 저자,
    c.category_name                 AS 카테고리,
    b.price                         AS 정가,
    COUNT(r.rental_id)              AS 총_대여건수,
    ROUND(
        CAST(COUNT(r.rental_id) AS REAL)
        / (SELECT COUNT(*) FROM rentals) * 100,
        1
    )                               AS 전체대비_비율_PCT
FROM books b
JOIN rentals r ON b.book_id = r.book_id
JOIN categories c ON b.category_id = c.category_id
GROUP BY b.book_id, b.title, b.author, c.category_name, b.price
ORDER BY 총_대여건수 DESC, b.book_id ASC
LIMIT 3;
```

### 실측 결과 (seed 데이터, LIMIT 3 적용)

| 순위 | book_id | 도서명 | 저자 | 카테고리 | 총 대여 건수 | 전체대비 비율 |
|---|---|---|---|---|---|---|
| 1 | 1 | 채식주의자 | 한강 | 소설 | 2 | 13.3% |
| 2 | 3 | 아주 작은 습관의 힘 | 제임스 클리어 | 자기계발 | 2 | 13.3% |
| 3 | 9 | 클린 코드 | 로버트 마틴 | 컴퓨터/IT | 2 | 13.3% |

> **동점자 분석 및 정렬 기준**: seed 데이터 특성상 대여 2회 도서가 총 4권(1, 3, 9, 10번)으로 4중 동점입니다. SQL의 `ORDER BY 총_대여건수 DESC, b.book_id ASC LIMIT 3` 결정론적 규칙에 따라 book_id 순서로 상위 3권이 산출되었습니다. (동점 4위: 10번 '부의 추월차선', 2회)

### 해석

- 2건씩 대여된 도서가 **4권 공동 1위**다(채식주의자·아주 작은 습관의 힘·클린 코드·부의 추월차선). 소설·자기계발·컴퓨터·경제경영이 각 1권씩으로, 특정 장르 쏠림이라기보다 **장르가 분산된 소수 선호**로 읽는 편이 정확하다.
- 1건 대여 7권, **대여 0건 2권**(소크라테스의 변명, 구름빵)이 있다. 이 2권은 Q07 LEFT JOIN + IS NULL 쿼리가 찾아내는 대상이다.
- 전체 15건 중 상위 4권이 8건(53.3%)을 차지해 상위 도서 집중도는 높다.

### 개선 액션

| 우선순위 | 액션 | 기대 효과 |
|---|---|---|
| 1 | TOP 3 도서 복본 1~2권 추가 구매 | 대기 없는 즉시 대여 가능, 회원 만족도 향상 |
| 2 | TOP 3 도서를 도서관 입구 추천 코너에 상시 전시 | 신규 회원 유입 및 대여 건수 추가 증가 |
| 3 | TOP 3 도서 저자의 동일 장르 신간을 우선 입고 | 연관 도서 대여 수요 창출 |

## KPI-3. 회원 연체율 (Member Overdue Rate)

### 정의

> **회원 연체율 = OVERDUE 상태 대여 건수 ÷ 전체 대여 건수 × 100 (%)**
>
> 도서 반납 관리 품질과 회원 준수율을 측정하는 핵심 서비스 지표이다.
> 연체율이 높을수록 다른 회원의 대여 기회가 줄어들고 도서 훼손 위험이 증가한다.

### 산출 SQL

```sql
-- KPI-3-A: 전체 연체율
SELECT
    COUNT(*)                                                AS 전체_대여건수,
    SUM(CASE WHEN status = 'OVERDUE' THEN 1 ELSE 0 END)    AS 연체_건수,
    SUM(CASE WHEN status = 'RETURNED' THEN 1 ELSE 0 END)   AS 반납완료_건수,
    SUM(CASE WHEN status = 'RENTED' THEN 1 ELSE 0 END)     AS 대여중_건수,
    ROUND(
        CAST(SUM(CASE WHEN status = 'OVERDUE' THEN 1 ELSE 0 END) AS REAL)
        / COUNT(*) * 100,
        1
    )                                                       AS 연체율_PCT
FROM rentals;

-- KPI-3-B: 회원별 연체 건수 및 개인 연체율 (연체 이력 보유 회원만)
SELECT
    m.member_id,
    m.name                                                  AS 회원명,
    COUNT(r.rental_id)                                      AS 개인_총대여건수,
    SUM(CASE WHEN r.status = 'OVERDUE' THEN 1 ELSE 0 END)  AS 개인_연체건수,
    ROUND(
        CAST(SUM(CASE WHEN r.status = 'OVERDUE' THEN 1 ELSE 0 END) AS REAL)
        / COUNT(r.rental_id) * 100,
        1
    )                                                       AS 개인_연체율_PCT
FROM members m
JOIN rentals r ON m.member_id = r.member_id
GROUP BY m.member_id, m.name
HAVING SUM(CASE WHEN r.status = 'OVERDUE' THEN 1 ELSE 0 END) > 0
ORDER BY 개인_연체건수 DESC, 개인_연체율_PCT DESC;
```

### 실측 결과

| 지표 | 값 |
|---|---|
| 전체 대여 건수 | 15 |
| 연체(OVERDUE) | 4 |
| 반납 완료(RETURNED) | 7 |
| 대여 중(RENTED) | 4 |
| **전체 연체율** | **26.7%** |

| 회원 | 총 대여 | 연체 | 개인 연체율 |
|---|---|---|---|
| 오태양 | 1 | 1 | 100.0% |
| 이서연 | 2 | 1 | 50.0% |
| 박지호 | 2 | 1 | 50.0% |
| 김민준 | 3 | 1 | 33.3% |

### 해석

- 15건 중 4건이 연체로 **전체 연체율 26.7%**다. 이는 일반적인 도서관 관리 목표(10% 이하)를 크게 웃도는 수준이다.
- 연체는 4명에게 1건씩 분산되어 있고, 오태양은 대여 1건이 전부 연체(개인 연체율 100%)다. **다건 연체자보다 단건 연체자가 많은 구조**여서, 개별 독촉보다 반납 알림 자동화의 효율이 높다.
- 연체 4건은 모두 `return_date IS NULL`이고 `due_date`가 이미 지난 상태다. Q14의 일괄 UPDATE가 이 조건을 그대로 사용한다.
- 4건 모두 2026년 6~7월 대여분으로, 장기 미반납이다. 알림·연장 정책이 없었음을 시사한다.

### 개선 액션

| 우선순위 | 액션 | 기대 효과 |
|---|---|---|
| 1 | 반납 기한 3일 전·당일·1일 후 자동 SMS/이메일 알림 발송 | 연체율 10%p 이상 즉시 감소 기대 |
| 2 | 연체율 30% 초과 회원에게 대여 가능 권수 제한(최대 1권) 적용 | 고위험 회원 관리 강화 |
| 3 | 연체 없이 10회 이상 대여한 우수 회원에게 대여 기간 연장 혜택 부여 | 준수 행동 긍정 강화 |
| 4 | 분기별 연체율 목표(15% → 10% → 5%) 단계적 설정 및 월간 모니터링 | 지속적 개선 문화 정착 |

## 경영 요약 (Executive Summary)

> 1. **대여 회전율**은 월 0.077~0.154(13권 중 1~2권)로 낮고 8~9월은 0이다. 저회전 도서 2권 정리와 비수기 프로그램으로 월 회전율 0.3 이상을 목표로 삼는다.
> 2. **최다 대여 도서**는 2건씩 4권(채식주의자·아주 작은 습관의 힘·클린 코드·부의 추월차선)으로 장르가 분산되어 있다. 복본 확충은 이 4권에 한정하고, 대여 0건 2권은 추천 코너로 회전을 유도한다.
> 3. **회원 연체율 26.7%**(15건 중 4건, 4명 각 1건)는 목표치 10%의 2.7배다. 단건 연체가 대부분이므로 반납 3일 전 자동 알림을 우선 도입해 다음 분기 15% 이하로 낮춘다.
